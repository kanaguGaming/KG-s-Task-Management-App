# Task Management Application

A complete Task Management Application built as a simple beginner-friendly web project using only HTML5, CSS3, and Vanilla JavaScript. The app uses `localStorage` for data persistence, requiring no backend or databases.

## Features

- **User Authentication**: Register and Login functionality.
- **Task CRUD**: Create, Read, Update, and Delete tasks.
- **Search & Filter**: Find tasks quickly and filter by status (Pending, In Progress, Completed).
- **Dynamic Dashboard**: Real-time statistics for tasks.
- **Responsive Design**: Works on Desktop, Tablet, and Mobile.
- **No Backend Required**: All data is stored in the browser's `localStorage`.

## Technologies Used

- **HTML5**: For page structure and semantics.
- **CSS3**: For layout, styling, and responsiveness (No external CSS frameworks used).
- **Vanilla JavaScript**: For logic, DOM manipulation, and data handling.

## How to Run

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
3. Create an account, log in, and start managing tasks!

## Project Structure

- `index.html`: Login page.
- `register.html`: Registration page.
- `dashboard.html`: Main dashboard for managing tasks.
- `css/style.css`: All application styling.
- `js/auth.js`: Logic for registration, login, logout, and session management.
- `js/tasks.js`: Logic for all task-related operations (CRUD, filtering, searching).
